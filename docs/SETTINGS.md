# 设置项说明

本文说明 Anyview 的设置分类、默认值、各平台差异及配置文件存储方式。所有设置项均集中定义于 `crates/anyview-core/src/settings.rs`。

## 设置窗口与生效方式

- 独立窗口，左侧为带图标的分类列表，右侧按功能分组呈现圆角卡片表单；底部提供「恢复本页默认」「取消」「确定」。
- 打开设置窗口时创建当前配置的草稿，所有修改在点击「确定」并通过校验后统一生效并持久化；切换分类不提交。
- 不适用于当前平台的选项自动隐藏；跨平台共享同一套配置键名。
- 右键菜单中的像素边缘处理、插值算法和图片效果为即时查看状态，切换后立即生效，并与设置项保持同步。

## 1. 一般

| 设置项 | 默认值 | 平台差异与说明 |
| --- | --- | --- |
| 拖动窗口时吸附边缘 | 关 | 拖动接近屏幕可用区域边缘 12 pt 内自动吸附；Linux 由窗口管理器负责，不显示 |
| 不保存浏览过的文件夹路径 | 关 | 开启后不记录最近打开历史（含 macOS 系统“最近使用”） |
| 不允许多个实例 | 关 | macOS 文案为“从访达打开图片时复用当前窗口”；Linux 经本机套接字将新图转交已有进程 |
| 删除文件时确认 | 开 | 移到回收站/废纸篓前弹确认对话框 |
| 在边角显示通知信息，而非中心 | 开 | 控制短提示通知的位置 |
| 总在最前 | 关 | 与快捷键 `Ctrl+A` / `⇧⌘A` 同步；Linux（GTK 4）不显示 |
| 按 ESC 退出 | 开 | 关闭后按 `Esc` 不退出程序 |
| 检查更新 | 关 | 预留项 |
| 到达首尾图片时执行 | 转到首个文件 | 可选：无操作、询问、转到首个文件、转到下一个/上一个文件夹或文件 |
| 到达压缩包内首尾图片时执行 | 转到首个文件 | 选项同上，与普通目录分别保存 |

| 更改默认背景图片 | 关（空） | 开启后使用指定图片填充铺放作为窗口背景 |
| 背景颜色 | `#202020` | 提供 15 个预设色块及系统取色器 |

## 3. 图像处理

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 根据 EXIF 信息自动旋转图片 | 开 | 按 EXIF Orientation 自动摆正 |
| 使用强锐化滤镜 | 关 | 配合“减淡+锐化”使用 |
| 预先读好接下来的图片 | 开 | 开启翻页方向后台预加载 |
| 预读张数 | 5 张 | 范围 1–20 张（反方向默认预读 1 张，双页 2 张） |
| 缓存大小 | 1024 MB | 范围 100–4096 MB，按解码像素字节计 |
| 图片大于窗口时显示图片顶部 | 开 | 适合看长图/漫画 |
| 先显示低品质图片以加速渲染 | 开 | 大图先显示 EXIF 缩略图预览，清晰图就绪后无缝替换 |
| 使用图片文件的 ICC 设置 | 开 | 按图片内嵌色彩配置文件还原色彩 |
| 使用监视器的 ICC 设置 | 关 | Windows 与 Linux（X11）按显示器配置文件转换色彩；macOS 由 ColorSync 处理，不显示 |
| 为 GIF 图片使用透明背景 | 默认 GIF 调色板 | 可选：默认 GIF 调色板、白色背景、网格背景 |
| 为 32 位图片使用透明背景 | 网格背景 | 可选：黑色背景、白色背景、网格背景 |
| 插值算法（裁剪滤镜） | Bilinear（快） | 可选：Bilinear、Bicubic、Lanczos；与右键菜单同步 |
| 翻页效果 | 无 | 可选：无、翻页、淡出、滑动 |

## 4. 格式关联

- **Windows**：提供按钮打开系统「默认应用」或按扩展名设置默认值（仅安装版启用）。
- **macOS**：提供「设为默认看图软件」与「打开访达」按钮及操作指引。
- **Linux**：提供写入用户 `mimeapps.list` 与恢复原默认程序按钮；Flatpak 下额外提供用户级文件管理器缩略图生成器登记/取消按钮。

## 5. 键盘

- 支持添加、启用/停用和删除自定义快捷键映射，实时检测与默认键位、已有行以及系统保留快捷键的冲突。
- 默认包含两条启用映射：`PageDown` → 下一个文件夹/压缩包，`PageUp` → 上一个文件夹/压缩包。

## 6. 鼠标

可分别自定义鼠标左键、中键、右键、侧键 X/Y、滚轮向上/向下映射（首项“默认”，其次“无操作”及全部可映射动作）；左键未自定义时支持「双击最大化/还原」（默认开）和「单击屏幕两侧时翻页」（默认关）。

## 7. 书签（压缩包位置记忆）

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 多窗口共享设置 | 开 | 仅多进程平台（Windows / Linux）显示 |
| 自动记忆当前图片在压缩包中的路径 | 开 | 再次打开同一压缩包时回到上次浏览位置 |
| 删除（按钮） | — | 清空所有已记忆的压缩包位置记录（需确认） |

## 8. 上下文菜单（仅 Windows 安装版）

- **在资源管理器中使用上下文菜单**（默认关）：为图片与压缩包添加右键菜单“用 Anyview 浏览图片”，可开关“显示软件图标”。
- **资源管理器缩略图预览**：分别控制 WebP、PSD、PSB 与其他格式（QOI、TGA、SVG、RAW 等，默认全开）；确定后立即更新当前用户注册表。

## 9. 杂项

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 图片文件夹 1 / 2 | 系统图片目录 / 空 | 快捷复制/移动目标目录 |
| 图像编辑器 | 空 | 配置外部编辑器路径（提供常见编辑器预设检测） |
| 翻页时播放音效 | 关 | 播放内置合成翻纸声 |
| 不打开 RAW 图片文件 | 关 | 浏览目录时忽略 RAW（直接打开仍可查看） |
| 打开 JPEG 时不打开同名 RAW | 开 | 同目录存在同名 JPEG 与 RAW 时仅保留 JPEG |
| 打开 RAW 时显示已有缩略图 | 开 | 优先读取内嵌预览；关闭后使用完整 RAW 解码 |
| 根据图片大小调节窗口大小 | 开 | 切换图片时自动调整窗口尺寸 |
| 看图时阻止屏保和显示器睡眠 | 关 | 播放或看图时阻止系统空闲息屏 |

## 10. 语言

支持“跟随系统”与 19 种内置界面语言，点击「确定」后立即生效。

## 配置文件的保存

- **格式**：带版本号的 TOML，原子写入（先写临时文件再重命名），未知键名原样保留以兼容新版。
- **路径**：
  - macOS：`~/Library/Application Support/Anyview/settings.toml`
  - Windows：`%APPDATA%\Anyview\settings.toml`
  - Linux：`$XDG_CONFIG_HOME/anyview/settings.toml`（默认 `~/.config/anyview/settings.toml`）
- **损坏恢复**：文件无法解析时自动备份为 `settings-broken-<时间戳>.toml`，恢复默认值并提示一次。
